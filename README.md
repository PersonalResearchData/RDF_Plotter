# RDF_Plotter
RDF_Plotter is a web tool to analysis for molecular dynamics simulation.
+ https://personalresearchdata.github.io/RDF_Plotter/

## How to use
1. Click the [ファイルを選択] button
![image](https://github.com/user-attachments/assets/bed56fc0-5ace-4881-ac20-8b3d34390ed3)

2. Select an *.xyz file
![image](https://github.com/user-attachments/assets/da9fae80-103e-4c63-a58c-a275e27c5f64)

3. Set the radius and number of bins

4. Click Plot
![image](https://github.com/user-attachments/assets/820aa91c-c31d-4efe-8664-81bde75bedba)
